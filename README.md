# Week 1 Project - 10Academy Challenge

## 📌 Overview

This project is part of the 10Academy Week 1 Challenge. The goal is to perform Exploratory Data Analysis (EDA) on a large financial news dataset.

## 📊 Exploratory Data Analysis (EDA)

- Loaded the dataset from Excel
- Dropped missing headline values
- Converted publication dates to datetime format
- Extracted date-only field and calculated headline length
- Visualized average headline length over time using Matplotlib

## 🔧 Tools Used

- Python 3.10
- Pandas, Matplotlib, Seaborn
- Git & GitHub for version control
